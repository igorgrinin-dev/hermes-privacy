Приложение: SERGEY Hermes
Владелец и единственный пользователь: Игорь Гринь, sergey.mainagent@gmail.com
Дата: 11 ноября 2026

1. Назначение приложения

SERGEY Hermes — персональный инструмент автоматизации, который использует API Google Drive для чтения, организации и резервного копирования файлов единственного аккаунта Google его владельца. Приложение не является публичным сервисом и не принимает сторонних пользователей.

2. Какие данные обрабатываются

Приложение получает доступ к файлам и папкам Google Drive исключительно того аккаунта Google, которым его авторизовал владелец (область доступа https://www.googleapis.com/auth/drive). Обрабатываются: имена файлов, их содержимое, метаданные (размер, даты, родительские папки), а также адрес электронной почты аккаунта — для подтверждения личности при авторизации.

3. Где хранятся данные

Файлы не покидают аккаунт Google владельца. OAuth-токены доступа хранятся локально на компьютере владельца в каталоге профиля Hermes и не передаются третьим лицам. Приложение не использует собственных серверов, не ведёт внешних баз данных и не отправляет содержимое файлов никому, кроме API Google.

4. Передача третьим лицам

Данные не продаются, не передаются и не раскрываются третьим лицам. Единственная внешняя система, с которой взаимодействует приложение, — API Google, принадлежащий Google LLC.

5. Хранение и удаление

Владелец может в любой момент отозвать доступ приложения к аккаунту на странице myaccount.google.com/permissions. После отзыва приложение теряет доступ, а локально сохранённые токены удаляются или становятся недействительными. Удаление файлов из Google Drive выполняется только по прямому указанию владельца.

6. Ограниченное использование

Использование данных Google API соответствует Google API Services User Data Policy, включая требования Limited Use. Данные используются только для функций, видимых и понятных владельцу аккаунта.
